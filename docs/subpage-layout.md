# 서브 페이지 공통 포맷

2026-10-15 사용자 선택: 후보 1 기업 소개형.

공통 제목/경로 → 본문 → 상담안내 박스 → 회사 푸터 순서.
본문 외곽 최대 1200px, 데스크톱 좌우 40px / 모바일 20px. 안쪽 본문 1120px와 상담 박스를 정렬.

|항목|데스크톱|태블릿 ≤900px|모바일 ≤600px|
|---|---|---|---|
|본문 상·하단|80px|64px|48px|
|연속 섹션|64px|48px|40px|
|일반 블록|32px|32px|24px|

구현: public-pages.ts의 subpage-standard, site-theme.css의 --subpage-* 변수.
인사말/연혁의 중복 외곽 여백은 공통 기준으로 대체. 카드 내부와 타임라인 항목 간격은 내용 전용 간격 유지.
상담 박스는 site-footer.ts에서 한 번 출력하며 화면 고정 오버레이로 만들지 않음. 실제 접수가 잠겨 있는 경우 기존 문의 안내 화면으로 연결.
타입 검사/테스트 136개 및 인사말/연혁 HTTP 200 확인. 시각 검수는 별도.
