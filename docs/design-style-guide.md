# 지엔씨쿨링 디자인 스타일 가이드

2026-10-15 사용자 확정 기준. 실제 예시는 `/style-guide#concept-intro`.

- 글꼴: Asta Sans. 문서 이미지 내부 서체는 UI 글꼴과 별도.
- 강조색: 딥 틸 #153D43. hover #0F2E33.
- 강조 배경의 주요 글자: #FFFFFF, 보조 글자 #9CC4CC.
- 일러스트: 동일 색상값 강제 대신 유사한 옅은 청록 계열, 굵은 선과 투톤 중심.
- 서브 페이지: 기업 소개형 공통 포맷. 영문 라벨 → 한글 타이틀 → 한 문장 소개, 로케이션, 본문, 공통 상담 박스, 푸터.
- 본문 기본 상하 여백 PC 80px / 태블릿 64px / 모바일 48px. 컨셉 도입부의 시작은 PC 48px / 모바일 32px 기준.
- 섹션 간격 64px / 48px / 40px. 일반 블록 32px / 32px / 24px.
- 컨셉 도입부: 왼쪽 영문 라벨·컨셉 제목·소개, 오른쪽 일러스트, 하단 1px 선. 그림 하단 약 1/3 잘림, 글자 위치를 그림 크기에 종속시키지 않음.
- 상세 컨셉 규격: [concept-intro-standard.md](concept-intro-standard.md).
- 페이지별 타이틀/소개: 프로젝트 outputs/화면문구/상단비주얼_타이틀및소개_20261015.md.
- 상담안내 박스는 연한 청록 배경과 둥근 문의 버튼으로 공통 푸터 상단에 구성.
- 모션은 reduced-motion 설정을 존중하고, 키보드/터치로도 주요 내용을 확인할 수 있게 구성.

새 페이지를 제작·수정할 때 이 기준과 AGENTS.md를 함께 따른다. 실제 페이지를 이번 저장 요청만으로 일괄 변경하지 않는다.

## 사업 검토 기준 및 푸터 상담 그림

- WHAT WE CONSIDER: 보조 배경 #F5F5F3, 직각 모서리, PC 내부 여백 32px 36px / 모바일 24px. 제목과 항목은 기존 표준 글꼴·라벨 간격 유지.
- 공통 상담 박스 앞쪽에 전화·대화·냉각 팬을 조합한 간결한 옅은 청록 일러스트 사용. PC 폭 110px, 모바일 60px. 설명과 문의 버튼의 가독성을 우선한다.

- 공통 푸터 상담안내 배경은 강조색 #153D43. 제목은 흰색, 라벨·설명은 #9CC4CC. 문의 버튼은 흰 배경에 강조색 글자로 적용한다.

- 보조 배경색의 표준은 #F5F5F3이다. FAQ·사업 검토 기준·진행 과정 등 보조 정보 박스에 적용하며 임의의 연한 청록색으로 바꾸지 않는다.

## 사업분야 상세 소섹션 표준

냉각탑 보수 페이지를 공통 기준으로 사용한다. 네 상세페이지 모두 세 소제목 앞에 각 내용에 맞는 단순한 옅은 청록색 일러스트를 배치한다. PC 폭 112px / 모바일 96px, 제목·이미지 위쪽 정렬. 섹션 간격 PC 32px / 모바일 24px, 첫 소섹션 위 구분선은 제거한다. 상단 컨셉 일러스트는 파일 끝이 아니라 설비의 바닥선과 구분선을 맞춘다.

## 제품소개 목록·상세

- 목록은 3개 제품 분류와 전체 제품 탐색. 제품 검색 박스와 상품 개수는 표시하지 않는다. PC 3열 / 태블릿·모바일 2열 제품 카드로 구성한다.
- 사진은 비율을 보존해 #F5F5F3 영역에 배치하고, 하단에 분류·제품명·소개와 밑줄 상세 링크를 둔다.
- 상세는 같은 컨셉 영역을 사용하고 PC 사진·설명 2열 / 모바일 1열. 사양표는 가로 스크롤과 첫 모델 열 고정으로 표시한다.
- 상담 준비 항목은 직각 보조 배경 박스. FAQ는 기존 사업분야의 번호·단일 열림·흐림에서 선명해지는 모션을 공유한다.
- 실제 설치 사례만 기존 사례 상세 페이지로 연결한다. 제품 데이터 관리: [product-catalog.md](product-catalog.md).

## 공통 위로 가기 버튼

공개 사이트 전반의 우측 하단 고정 컨트롤. 검정 50% 반투명 배경·12px 블러·둥근 사각형·1px 흰색 테두리·2.5px 굵기의 흰색 위 화살표. PC 48px/모바일 44px. 320px 스크롤 이후 표시하며 모바일 메뉴가 열린 동안 숨긴다. 모션 감소 설정에서는 즉시 이동한다.

## 영문 라벨·한글 제목 공통 간격

모든 공개 페이지의 영문명+한글명 세트는 영문 라벨 아래 4px, 한글 제목 위 여백 0으로 통일한다. 메인·상단 비주얼·컨셉·본문 제목·제품 카드·상담 박스에 적용한다. 섹션 제목 묶음과 다음 박스·구분선은 PC 12px/모바일 10px를 기준으로 하고 제목과 옆 설명은 하단 정렬한다. 제목 아래 소개 문장이 이어지는 컨셉 영역은 소개의 기존 여백과 그림 배치를 유지한다. 공통 변수 `--heading-label-gap`, `--heading-content-gap`으로 관리한다.

## 로케이션 메뉴 폭

모든 공개 페이지의 로케이션 메뉴 칸은 PC 220px로 동일하게 사용한다. 마지막 단계·제품 상세의 별도 가변 폭은 사용하지 않는다. 900px 이하에서는 홈 아이콘 40px를 제외한 나머지 폭을 메뉴 단계 수에 따라 균등 분배한다. 드롭다운은 해당 칸과 같은 폭을 사용한다.
