## 첫 작업 결과와 한계

`src/access-policy.ts`에 계정 상태·세 역할·콘텐츠/문의/직원/삭제복구/본인 권한과 메뉴·기본 첫 화면·재인증 복귀 정책을 추가했다. 알려진 관리자 경로만 복귀를 허용하며 현재 역할로 다시 검사한다. 이 함수에는 반드시 서버에서 검증한 최신 계정 정보를 전달해야 한다.

`src/index.ts`는 실제 인증 연결 전 관리자·본인 문의 화면/API를 401, 직원 로그인/인증 경로를 준비 중 503, 파일/업로드를 404로 차단한다. 비공개 응답은 no-store·no-referrer이고 데이터/파일/정적 자산 제공 전에 처리한다. 헤더·쿠키·쿼리 역할을 신뢰하지 않는다. 모든 경로에서 Workers를 먼저 실행하도록 설정했다. 기존 공개 HTML·health 처리는 유지했다.

실제 직원 로그인·세션·DB 역할 조회·즉시 권한 회수·403 업무 API·파일별 권한·마지막 책임자 보호는 미구현이다. 메뉴/첫 화면 함수는 향후 인증·화면 연결용이며 현재 로그인 결과가 아니다. DB 마이그레이션과 사용자 화면은 이번에 변경하지 않았다.

# 현재 후속 구현 안내

사용자 선택을 반영한 홈페이지 전용 이메일·비밀번호, 로컬 HTTPS, 별도 실제 검사 서비스의 현재 구현은 [MVP C 로컬 안내](mvp-c-local.md)를 따른다. 아래 단계별 기록은 각 작업 당시 상태이며 실제 직원의 비밀번호 설정·초대 수락과 회사 업무 검수는 별도로 기록한다.
