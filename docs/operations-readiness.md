# 운영 준비: 임시파일 삭제 재시도 — 2026-10-11

회사 운영 정책과 실제 기능 검수는 아직 미승인·미실시다. 이 작업은 개발 단계의 임시파일 정리 보완이다.

- 만료된 미사용 업로드만 삭제 작업에 등록한다. 고객 제출 완료 자료, 연결된 파일, 문의와 콘텐츠의 보관 기간은 자동 적용하지 않는다.
- R2 원본과 검사 결과 객체 모두 제거돼야 완료로 기록한다. 일부 삭제 실패는 1분·5분·30분·2시간 간격으로 재시도하며 이후에도 2시간 간격을 유지한다. 객체 키는 변경하지 않으므로 중복 실행의 삭제는 멱등이다.
- 차단 직후 실행이 중단된 경우 다음 정리 실행에서 작업 등록을 복구한다. 완료 기록은 D1에 남긴다. 파일 이름·문의 원문을 오류 메시지에 넣지 않는다.
- attached 표시, 제품 이미지 참조와 견적 PDF 참조가 남은 파일은 삭제하지 않는다. 보류 작업은 완료 처리하지 않는다.
- 정기 작업 한 단계 실패 후에도 다른 단계를 실행한다. 실패 단계 이름만 오류로 보고하며 오류를 성공으로 숨기지 않는다.

## 검증

전체 자동 테스트 98개 통과. 타입 검사와 배포 전 빌드 통과. 부분 R2 삭제 실패/재시도/완료 후 재삭제 방지, 참조 파일 보호, 등록 중단 복구, 정기 작업 장애 분리를 메모리 DB와 모의 R2로 검증했다. 실제 외부 R2 장애 시험 및 운영자 알림 전송은 미실시다.

로컬 DB 백업 후 0009 마이그레이션 적용. 실제 직원·문의·파일·삭제 작업은 모두 0건이며 외래키 오류도 0건이다. 건강 확인·공지·문의 안내 200, 미설정 로그인 503, 비로그인 관리자 문의 API 401 확인. 실제 접수 잠금과 미리보기 서버 유지.

## 남은 운영 준비

회사 승인 정책 버전/시행일/보관 기간/삭제 요청 확인 절차를 확정해야 한다. 문의 영구 삭제, 보관 예외와 삭제 대장, 백업 복원 시 삭제·최신 권한 재적용은 아직 구현·검수 전이다. 발송 결과 불명 조회, 확인 메일의 불명 상태 처리, 실패 담당자 알림도 남아 있다. 승인 전에는 영구 삭제 자동화를 활성화하지 않는다. 이번 작업만으로 운영 준비 완료 또는 회사 기능 검수 통과를 선언하지 않는다.
