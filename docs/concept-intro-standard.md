# 본문 상단 컨셉 영역 디자인 기준

사용자 확정: 2026-10-15. 기준 화면: `/company/certifications`.

## 구성

로케이션 → 컨셉 영역 → 페이지 본문.
컨셉 영역은 왼쪽 문구, 오른쪽 상징 일러스트, 하단 얇은 구분선으로 구성한다. 상단 비주얼의 페이지 타이틀/소개와는 별도 영역이다.

- 작은 영문 라벨: Asta Sans 12px, 자간 .12em.
- 컨셉 제목: Asta Sans, PC 30~44px 반응형, 굵기 500, 줄높이 1.28, 자간 -.04em. 라벨 아래 10px, 제목 아래 12px.
- 소개: 15px, 줄높이 1.6. PC 한 줄이 가능한 분량, 좁은 화면은 자연스러운 줄바꿈.
- 본문 시작부터 문구 상단: PC 48px / 모바일 32px. 일러스트 높이로 인해 이 간격이 늘어나면 안 된다.
- 소개와 하단 선: PC 16px, 모바일은 배치에 맞게 조정.
- 오른쪽 그림: 딥 틸 테마와 유사한 옅은 청록 계열, 굵은 선과 투톤 중심. 주제에 맞게 개별 제작. 인증서 그림을 다른 페이지에 그대로 반복하지 않는다.
- 그림 높이 기준: PC 260px / 태블릿 220px / 모바일 180px. 텍스트와 독립적인 크기를 유지한다.
- 그림 하단은 구분선에 붙여 약 1/3 잘림 효과를 준다. 텍스트를 하단 정렬하여 위 여백이 커지는 방식은 피한다.
- 하단 선: 본문과 같은 폭, 1px. 테마의 어두운 청록 계열.
- 본문 폭과 좌우 여백은 공통 서브 페이지 기준을 따른다. 모바일은 한 열로 조정.
