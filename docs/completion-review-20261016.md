## 관리자

DB 직원 인증·역할·권한, Access 원격 보호 유지. 제품 메뉴는 ‘제품 DB 보관 자료’로 구분하고 파일 카탈로그 수정 위치 및 공개 목록 미반영을 설명한다. 기존 DB 제품·모델·사진·분류 기능은 보존한다.

콘텐츠 목록·편집에는 저장 → 첨부/검사 → 미리보기 → 공개 순서를 안내한다. 시공 사례의 공개 확인 정보·대표 사진, 자료의 PDF 조건은 서버 검증을 유지한다. 모바일 메뉴·입력·오류 문구·표 스크롤을 보완한다. 공개·숨김·삭제·복구와 역할 차단은 격리된 시험 DB에서 검증한다.

## 회사 자료가 있어야 가능한 후속 등록

- 공개 승인된 실제 시공 사진·사례 설명·확인자/확인일
- 제품별 실제 사례 ID 대응표
- 게시할 실제 PDF 파일과 제목·분류·설명 및 공개 범위
- 실제 회사 공지
- 승인된 개인정보 처리 기준 및 별도 고객 접수 활성화 요청

기존 카탈로그 원본은 참고 자료로 보존하며 현재 공급·공개 여부를 추정해 게시하지 않는다.

## 업로드

기존 저장소 루트는 website이며 `main`, 원격 `https://github.com/sminsik/gnc-cooling-website.git`이다. 누적된 기존 승인 작업과 이번 보완을 함께 업로드한다. `.gitignore`에 로컬 작업·로그·DB·인증서를 추가했다. 로컬 DB·환경 변수·인증정보·작업 로그는 커밋하지 않는다. 원격 공개 범위는 변경하지 않는다. 운영 배포·DNS 변경은 하지 않는다.

그림: imagegen 생성, `public/generated/support-{projects,resources,notices,as,consultation}-v1.png`. 옅은 청록 굵은 선, 평면 표현, 투명 배경. 회사 실적 사진으로 사용하지 않는다.
