# 지엔씨쿨링 홈페이지 개발 환경

기존 sources/와 outputs/는 참고 자료로 유지하고 개발은 이 폴더에서 진행합니다.

## 실행

Node.js 22 이상과 pnpm을 사용합니다. `pnpm install` 후 `pnpm db:local`, `pnpm dev` 순서로 실행합니다. 미리보기 주소는 http://127.0.0.1:8787 입니다.

`pnpm check`는 코드 검사, `pnpm build`는 실제 배포 없이 Cloudflare 실행 파일 생성 여부를 확인합니다.

## 구성

- public/: 정적 소개 페이지와 화면 스타일
- src/: Cloudflare Workers 프로그램
- migrations/: D1 테이블 변경 기록
- docs/: 개발 순서와 운영 연결 계획
- .wrangler/: 로컬 D1·R2 시험 데이터. Git에 포함하지 않습니다.

현재는 로컬 개발 전용입니다. wrangler.jsonc의 데이터베이스 ID는 로컬용 임시 값이며 실제 배포에 사용할 수 없습니다. 계정 로그인·원격 서비스 생성·도메인 변경은 수행하지 않았습니다.

## 개발과 공개 순서

1. 메인·정적 페이지와 제품 목록·상세 화면을 검토합니다.
2. 제품·사례·자료실 관리와 직원 인증을 구현합니다.
3. 고객 접수·본인 확인·답변·견적·첨부 권한을 구현합니다.
4. Cloudflare 계정 연결 후 개발용 D1·R2를 별도로 생성합니다.
5. 비공개 시험 주소에서 이메일·스팸·자료 접근·복구를 확인합니다.
6. 운영용 D1·R2와 비밀값을 별도로 설정하고 기존 도메인을 전환합니다.

실제 고객 개인정보를 로컬 시연 자료나 Git 저장소에 넣지 않습니다. 개발·시험·운영의 데이터와 파일은 분리합니다. 고객 데이터·비공개 파일 API는 인증과 권한 검증이 완성되기 전 제공하지 않습니다.
